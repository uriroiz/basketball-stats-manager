# תכנית מימוש מוצעת — Insights היסטוריים לשדרנים

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**מצב:** הצעה לבחינת המשתמש; טרם אושרה וטרם מומשה.

**Goal:** להכין דוח עם סיפורי עבר רלוונטיים למשחק ולמחזור כבר בתחילת 2026/27, ולשלבם בהמשך עם ה־Insights הקיימים.

**Architecture:** להשאיר את המנוע העונתי, ולהוסיף שירות הקשר למשחק ומנוע היסטורי ממוקד. דוח אחד שומר את העובדות, הראיות, מצב המקורות ובחירת הסיפורים; המסך והייצוא צורכים אותו. אין הזנת שלוש העונות כאילו היו עונה אחת.

**Tech Stack:** JavaScript הקיים, IBBA API ודפי האיגוד, בדיקות Node/VM, ייצוא Excel הקיים. ללא תלויות או מסד נתונים חדשים.

**Spec:** [הצעת המפרט](../specs/2026-10-06-historical-broadcast-insights-design.md). היא מרחיבה את מפרט שלוש העונות הקיים; אישורו הקודם אינו אישור לפיתוח ההרחבה החדשה.

## Global Constraints

- שלוש העונות הקיימות בלבד: 2024-25, 2025-26, 2026-27. הכנה למשחק עתידי בעונה הפעילה האחרונה בלבד.
- היסטוריה מסומנת בעונה, בקבוצה ההיסטורית, במספר משחקים ובמקור. אין הסקת סגל נוכחי מן העבר.
- זהות רשמית בלבד לקבוצות ולשחקנים; אין חיבור לפי שם או חולצה.
- להמשיך בניתוחים הקיימים; אין יצירת ממוצעים היסטוריים חלופיים, תחזיות או דירוג מחזור משוחזר.
- ספירת ניצחונות/הפסדים מתוצאות רשמיות מותרת ומסומנת כסיכום משחקים. סיכומים וממוצעים עונתיים היסטוריים נלקחים כפי שפרסם האיגוד.
- השוואת מחזורים לעונה סדירה בלבד לאחר אימות משמעות המחזור. לא להחליף מחזור במספר המשחק הכרונולוגי.
- אין טענות מעבר לחלון העונות שנבדק. אין מכסת תובנות מחייבת או סיפורים המומצאים כדי להשלים כמות.
- לעבוד במסלול האתר הפעיל בלבד, לשמר שינויים קודמים, לא להרחיב הרשאות proxy ולא לפרסם במסגרת משימה זו.

## Review Focus

1. משחק נדחה: מחזורו המקורי אינו סדר משחקיו; השוואה מציינת את מספר המשחקים שהושלמו.
2. מקור חסר: תוצאה קיימת ללא שחקנים מאפשרת סיפור תוצאה, אך לא סיפור שחקן או טענת שיא/רצף מלא.
3. זהות משתנה: שם חסות שונה אינו מנתק קבוצה מאומתת; שחקן שעבר קבוצה שומר את קבוצתו ההיסטורית.
4. תגובות מאוחרות: בחירת משחק/עונה חדשה או רענון אינם מאפשרים להיסטוריה ישנה לשנות דוח חדש.
5. ניסוח וייצוא: החלפת ניסוח וייצוא בזמן טעינה אינם משמיטים עונה, מקור, מכנה או מצב נתונים.

## סדר וגבולות המימוש

משימות 1–4 מספקות את הערך הראשוני לשידורים: מחזורים, פתיחות עונה ומפגשים קודמים. משימה 5 מוסיפה סיפורי שחקנים ורקע רשמי; משימה 6 משלימה ייצוא ואימות. כל המשימות שייכות לתכנית, אך כשל במקור סיכומי קבוצות לא יעכב מסירת סיפורי משחקים מאומתים. אין החלפה מלאה של מנוע V2 ואין שכתוב כל האתר.

### משימה 3 — סיפורי מחזור ומפגשים קודמים עם ראיות

## מחוץ לתכולה

תחזיות ותוצאות משוערות; סטטיסטיקה בזמן אמת במהלך שידור; עונות מחוץ לשלוש; שיאי קריירה או כל הזמנים; חיבורי סגל לא מאומתים; חישוב ממוצעי מחזור חדשים; שחזור דירוג ליגה בעבר; פרשנות שינוי סגנון כאילו סגלים לא השתנו; הגדלת מספר ניסוחים אקראיים כתחליף להוספת מידע.

## המלצת ביצוע

מימוש ברצף באותה שיחה באמצעות `superpowers:executing-plans`: המשימות תלויות בנרמול המקור ובחוזה הדוח המשותף. התכנית נכתבה לבקשת המשתמש כטיוטה מלאה לעיון; אין לבצע שינוי מוצר עד אישורה.
